Privacy Policy — Vaultwarden for TerraMaster TOS

Applies to the community package of Vaultwarden distributed via the TOS App Center. Last updated: 2026-09.

Summary

This package contains no telemetry, no analytics and no crash reporting. Neither the installer scripts nor the Vaultwarden server send any usage data to the packager or to anyone else. Your password vault never leaves your NAS unless you explicitly configure it to.

What we do not collect

  • No usage statistics, no device fingerprints, no analytics.
  • No crash reports or error reports are sent anywhere.
  • No vault data, account data or master passwords ever leave your NAS.
  • The installer performs no network downloads: the complete application (server binary and web vault) ships inside the package.

Where your data lives

  • Accounts, organizations, vault items, attachments, sends and the icon cache are stored locally in /var/lib/vaultwarden/ (SQLite database plus folders).
  • Everything is end-to-end encrypted with your master password (zero-knowledge); the server stores ciphertext it cannot read.
  • Uninstalling with apt remove keeps this data; apt purge deletes it.
  • The randomly generated ADMIN_TOKEN for the admin panel is written to /usr/local/vaultwarden/vaultwarden.env on your NAS only.

Network access

  • The web vault and the Bitwarden API are served only on your local network via the TOS gateway route /vaultwarden/; the service itself listens on loopback and is not reachable from outside directly.
  • Website icons (favicons): by default Vaultwarden downloads favicons from the public websites referenced by your vault entries and caches them locally, so other sites can see your NAS IP address. To disable this outbound feature, set ICON_SERVICE=internal in /usr/local/vaultwarden/vaultwarden.env.
  • Optional integrations you control (all disabled by default): SMTP email for invitations and password hints, Duo / FIDO2 WebAuthn passkeys, and HTTPS certificates. They only connect to endpoints you configure yourself.

Client apps

Bitwarden browser extensions, desktop and mobile apps connect directly to your NAS (http(s)://<your NAS>/vaultwarden). Traffic between clients and the server stays on your network; no Bitwarden cloud servers are involved.

Third-party software

This package redistributes the open-source Vaultwarden server (AGPL-3.0, by Daniel García) and its official web vault, built from public sources. See the package PROVENANCE.md and the linked source repository for build provenance.

Contact

Packaging issues: the package repository listed in the App Center entry. Upstream application issues: the Vaultwarden project.

隐私政策 — Vaultwarden for TerraMaster TOS

适用于经 TOS 应用中心分发的 Vaultwarden 社区封装包。最近更新：2026-09。

摘要

本包不含任何遥测、统计与崩溃上报：安装脚本与服务端都不会向打包者 或任何第三方发送使用数据。除非您主动配置，密码库数据绝不离开您的 NAS。

我们不收集什么

  • 不收集使用统计、设备指纹或分析数据。
  • 不发送任何崩溃或错误报告。
  • 密码库数据、账号数据与主密码永不离开您的 NAS。
  • 安装过程零联网下载：完整应用（服务端与网页保管库）随包内置。

数据存放位置

  • 账号、组织、密码库条目、附件、Send 与图标缓存均存放在本机 /var/lib/vaultwarden/（SQLite 数据库及子目录）。
  • 全部数据经主密码端到端加密（零知识架构），服务器本身无法解读密文。
  • apt remove 卸载保留上述数据；apt purge 彻底删除。
  • 首装随机生成的管理后台令牌 ADMIN_TOKEN 只写入您 NAS 上的 /usr/local/vaultwarden/vaultwarden.env。

网络访问

  • 网页保管库与 Bitwarden API 仅通过 TOS 网关路由 /vaultwarden/ 在您 的局域网内提供服务；服务本体仅监听回环地址，无法被外部直连。
  • 网站图标（favicon）：默认情况下 Vaultwarden 会向密码库条目所 指向的公网站点请求 favicon 并缓存到本机，因此相关网站可以见到您 NAS 的 IP。如需 关闭此出站行为，在 /usr/local/vaultwarden/vaultwarden.env 设置 ICON_SERVICE=internal。
  • 由您掌控的可选外联（默认全部关闭）：用于邀请与密码提示的 SMTP 邮件、Duo / FIDO2 WebAuthn 通行密钥、HTTPS 证书。它们只会连接您自行配置的 地址。

客户端应用

Bitwarden 浏览器插件、桌面端与移动 App 直连您的 NAS （http(s)://<你的NAS>/vaultwarden）。客户端与服务端之间的流量始终 在您的网络内，不涉及 Bitwarden 官方云。

第三方软件

本包再分发开源的 Vaultwarden 服务端（AGPL-3.0，作者 Daniel García）及其官方网页 保管库，均由公开源码构建。构建溯源见包内 PROVENANCE.md 及应用中心条目 链接的源码仓库。

联系方式

封装问题：应用中心条目所列仓库。上游应用问题： Vaultwarden 项目。
